Importing points of presence

Open Points › + (or the Bench when it is empty). You can add points in five ways:

  • Scan a QR code — with the camera or from a picture in Photos.
  • From the clipboard — one link, a subscription URL, or many lines at once; links and subscriptions can be mixed.
  • Subscription link — an https:// address from your provider. You can add several subscriptions; each refreshes on its own interval (default 24 h).
  • File — .conf (WireGuard/AmneziaWG), .json (Xray, sing-box), .yaml (Clash/Mihomo proxies), .txt.
  • Manually — every field for VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard-compatible, AmneziaWG, SOCKS5 and HTTP.

Every import opens a preview: you see each point, its protocol and whether it can be used for checks and for the tunnel, and you confirm before anything is saved. After adding, Isoline measures each point's exit and gives it a callsign such as DE-FRA-01 (country · node · number).

Not supported: OpenVPN .ovpn files and encrypted links of other apps that cannot be decrypted. Isoline tells you when it meets them.

Subscriptions that ask for device binding (HWID)

Some providers limit how many devices may use a subscription. Until the app identifies the device, they return placeholder entries (for example a point at 0.0.0.0 with a name mentioning HWID). Isoline recognises this, does not import the placeholders and asks you:

  • Allow and load — the app sends to that provider only a random identifier of this installation (not a hardware or advertising ID), the system name and version, and the generic device model, and loads the subscription again.
  • Cancel — nothing is sent.

You can change the choice per subscription (subscription card › “Send device identifier”) and see or reset the identifier in Settings › Privacy › Install identifier. If the provider answers “device limit reached”, remove an old device in your provider's account. Details: Privacy Policy, section 6.

The device tunnel (VPN) and its permission

Checks in the Bench do not need the VPN: each channel uses its own isolated connection inside the app. The VPN permission is needed only for the device tunnel, which routes the traffic of the whole device (for example to test other apps from a region).

  1. Open the Tunnel tab, choose a point and move the lever to “On”.
  2. Read the explanation screen and tap “Continue”.
  3. The system asks to add a VPN configuration — allow it. On iPhone this may require your passcode or Face ID.

To turn it off, move the lever back, use Settings › VPN in the app, the system VPN settings, or (Android) the notification and Quick Settings tile. Removing the VPN configuration in system settings is also safe; the app asks again next time.

Troubleshooting

A point shows “not reachable” or a timeout

Check that the configuration is current (refresh the subscription), that your network allows outgoing connections to the server's port, and try Bench › Channel diagnostics. If the same configuration works elsewhere, send us the diagnostic log (see below).

The import says “not supported”

The preview explains why: for example an unsupported protocol (TUIC, OpenVPN), a transport the core does not support, or an insecure TLS setting that is admitted for checks but not for the tunnel. Ask your provider for a link in one of the supported formats.

All channels show the same country

The exit country is measured, not taken from the name. Several points of one provider can exit in the same country even if they are named differently. The badge next to the callsign shows the source of the country (measured or “by name”).

The tunnel turns on but there is no internet

Try another point, turn off “Connect on demand” and custom routing rules, or switch DNS back to the default in Settings › DNS. Some networks block VPN protocols; that is outside the app's control.

Prices are not converted

Conversion uses the daily ECB reference rates. If the rates cannot be loaded (for example offline), prices are shown in the original currency.

How to report a problem

  1. In Settings › Log, set the level to “Debug” and reproduce the problem.
  2. Tap Share. The app removes UUIDs, passwords and keys from the log before sharing.
  3. Send it to vojkovic@conciergegroup.pro with the app version (Settings › About), your device and system version, the protocol of the point and what you expected to happen.

Please do not send us full configurations, subscription URLs or passwords.

Deleting your data

All data is on your device. Use Settings › Data › Erase all data, or delete the app. We hold no app data about you. Full details: Privacy Policy › Data deletion.

For VPN providers

Isoline is a neutral client without accounts or purchases. If your users want to open your subscriptions in Isoline, this is what the app understands. This section is informational and may change with app updates.

Subscription formats

  • Plain text or base64: one share link per line (vless://, vmess://, trojan://, ss://, hysteria2:///hy2://, wireguard:///wg://, amneziawg:///awg://, socks://, http(s)://user:pass@host:port), optional #key: value metadata in the first 10 lines;
  • Xray JSON (object or array), sing-box JSON (outbounds), Clash/Mihomo YAML (proxies), SIP008, WireGuard/AmneziaWG .conf, AmneziaWG JSON container.

Serve subscriptions over HTTPS only.

Response headers we read

HeaderUse
profile-title (plain or base64:)Subscription name (fallbacks: subscription-name, content-disposition file name)
profile-update-intervalRefresh interval in hours (the user can override)
subscription-userinfoupload, download, total, expire — shown as information
support-url, support-email, profile-web-page-urlShown as plain text in the subscription card
announce, announce-url, profile-description“Message from the provider” block (not a pop-up)
routing, routing-enableSimple routing rules, applied only after the user reviews and accepts them
sort-orderping, name or none

Ignored on purpose (shown as “rejected” in the subscription inspector): directives that hide settings or the VPN icon, silently change the subscription URL (new-url, new-domain), connect automatically, banners and colour profiles, and x-hwid-* response headers. The user always sees and controls every configuration.

Request headers: User-Agent: Isoline/<version> (<OS> <version>), Accept: */*, Basic auth from the URL. Device headers (x-hwid, x-device-os, x-ver-os, x-device-model) are sent only after the user allows device binding for that subscription.

Deep links

Every link opens an import preview that the user confirms; nothing is imported silently.

isoline://import?url={url-encoded subscription URL}&name={url-encoded name}
isoline://import/{raw share link or subscription URL}#name
isoline://add-pop?uri={url-encoded share link}
isoline://open?url={url-encoded address}&pop={callsign}
isoline://compare?url={url-encoded address}&pops=DE-FRA-01,JP-TYO-01

In the app, Settings › For providers has a link generator (link and QR code) and a subscription inspector that shows which headers were accepted or rejected. For a QR code, use error correction level M.
