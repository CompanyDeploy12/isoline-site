2. Xray-core и другие компоненты под MPL-2.0 — исходный код

Xray-core (github.com/XTLS/Xray-core), REALITY (github.com/XTLS/REALITY) и gopher-luar распространяются по Mozilla Public License 2.0. Приложения используют их в том виде, в каком их опубликовали авторы, без изменений файлов под MPL:

  • Xray-core: коммит 676eaf66f8f0 (версия Go v1.260327.1-0.20261109052709-676eaf66f8f0), исходный код: github.com/XTLS/Xray-core/tree/676eaf66f8f0;
  • REALITY: коммит 4bb46b2afd8b, исходный код: github.com/XTLS/REALITY;
  • gopher-luar: версия v1.0.11, исходный код: github.com/layeh/gopher-luar.

Если в будущей версии приложений появятся изменения файлов под MPL, изменённый исходный код будет опубликован, а ссылка на него появится здесь и в примечаниях к выпуску. Исходный код любого компонента под MPL из приложений можно также запросить по адресу vojkovic@conciergegroup.pro.

juju/ratelimit распространяется по GNU LGPL 3.0 с исключением для статической компоновки, которое разрешает распространять комбинированные работы без предоставления дополнительного исходного кода.
